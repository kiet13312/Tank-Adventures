# Tank Adventures

Game tank 2D Android màn hình ngang.

## Tính năng
- 15 màn chơi, mỗi màn 60 giây và 15 xe địch.
- Thắng cùng một màn 2 lần để mở màn tiếp theo.
- Mỗi lần thắng nhận 100 xu.
- 4 xe: Scout, Panzer, Tiger, Titan; giá 0 / 1000 / 2000 / 3000 xu.
- Joystick trái để di chuyển, joystick phải để ngắm; xe có gia tốc và giảm tốc.
- Xe địch màu xám, chậm hơn xe người chơi và bắn mỗi 3 giây.
- Xe người chơi bắn mỗi 3 giây.
- Hòm thính: hồi đầy HP hoặc đạn lớn trong 60 giây.
- Màn 15 có boss đứng yên, mạnh hơn xe người chơi.

APK debug được build tự động bằng GitHub Actions.
